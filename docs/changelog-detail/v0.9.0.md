## v0.9.0 (2026-10-11)

Since v0.8.0: a committed `.forge.conf` can no longer send the Forgejo token to an arbitrary host
(a host allowlist, https only, no redirects, and the token kept off argv; see the migration note),
a new `context-budget` skill measures how much a project loads before the first prompt, and the
review lows that had piled up as bundle tickets were triaged: each item fixed, dropped with its
reason, or moved to a single-problem ticket, which took the open count from 40 to 25.

### Security

- **A committed `.forge.conf` could send the Forgejo token to any host, over http, through a redirect, or from any environment variable** (`forge-lib-version` 35 to 36, `forge-host-version` 33 to 34, `github-to-forgejo-version` 9 to 10, `health-check-version` 7 to 8, `forge-adapt-version` 73 to 74, `forge-kit-devops` 0.21.3 to 0.22.0, `forge-kit-adapt` 0.12.1 to 0.12.2; #442; `scripts/test-forge-lib.sh` 539 passed, 0 failed). Cloning a repository and running any forge-lib caller sent `Authorization: token` to whatever `FORGE_API_URL` the file named, followed redirects with it, and read the token from whatever variable `FORGE_TOKEN_ENV` named, `AWS_SECRET_ACCESS_KEY` included; `health-check` step 9 also expanded that name with `${!var}`, which runs a command substitution hidden in an array subscript. Now a URL read from the file gets the token only when its host, port included, is a line in `${XDG_CONFIG_HOME:-$HOME/.config}/forge/hosts`, and the refusal prints the exact command that adds it. The URL is refused before parsing when its authority carries userinfo or it holds a backslash or a non-printable byte anywhere, and the host must be plain letters, digits, dots and dashes with an optional numeric port. The URL must be https unless `FORGE_ALLOW_HTTP=1` is exported (the file cannot set it), curl runs with `--proto`, `-g` and `--url` and without `-L`, so a 3xx is rc 22, and the token reaches curl through `-K`, never argv. `FORGE_TOKEN_ENV` must be a valid name, and in the file only `FORGEJO_TOKEN` or `FORGE_TOKEN`; an empty one still means the default. A token with a quote, backslash or control character is refused, xtrace is suspended around the token, and the new `forge_token_present` reports the variable name and whether it is set without printing it, which `health-check` now uses. A URL or token name you export yourself is trusted as before. 55 new rows fail against v35, including a real two-listener redirect; eight named mutants each remove one guard, three of them the review's re-source, strict-`IFS` and `set -a` fixes, and each turns its row red.

  **Migration:** on each machine, add your Forgejo host (with its port, if the URL has one) to the allowlist, once: `mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/forge" && printf '%s\n' forge.example.com >> "${XDG_CONFIG_HOME:-$HOME/.config}/forge/hosts"`. An http-only instance also needs `export FORGE_ALLOW_HTTP=1`. A `.forge.conf` naming a token variable other than `FORGEJO_TOKEN` or `FORGE_TOKEN` must drop that line and export `FORGE_TOKEN_ENV` instead. Installed `scripts/forge-lib.sh` copies keep the old behaviour until refreshed with `forge-adapt`.

### Added

- **A `context-budget` skill and shell asset report, in characters, how much a project's next session loads before the first prompt** (new shell asset `context-budget-version` 3, new skill `context-budget-version` 1, `health-check-version` 6 to 7, `forge-kit-devops` 0.20.9 to 0.21.2, `forge-kit-adapt` 0.12.0 to 0.12.1; #297; new `scripts/test-context-budget.sh`, 164 passed, 0 failed, wired into CI). One downstream repository loaded about 258 KB of `@`-imports into every session, subagent and compaction, and nothing measured it; Claude Code's own notices are interactive and carry no exit code. `context-budget.sh [<repo-dir>]` totals `CLAUDE.md`, its `@`-imports to four hops (each file once, nothing outside the project, the grammar `/context` showed on 2.1.287 and 2.1.295) and the loaded portion of the auto-memory `MEMORY.md` (200 lines or 25,000 bytes), counting code points identically in every locale. It warns on stderr from 40,000 and exits 1 at 80,000, unless one valid `<!-- context-budget: <N> reason: <text> -->` marker raises that project's level (a broken marker exits 2). A `##` section over 8,000 characters is a report-only move candidate. `--sweep <root>...` lists every repository under the roots, largest first, and exits 0. It prints paths, sizes and levels, never file text other than a single-repository heading, and is wired into no hook, workflow or pre-push. `health-check` reports the figure as one advisory step, `forge-adapt` recommends the skill from a `references/skills.md` row (no word added to `adapt`), and `docs/guides/startup-context.md` carries the rules and the prune recipe. All nine listed mutants die, and the suite passes under gawk, mawk and busybox awk.
