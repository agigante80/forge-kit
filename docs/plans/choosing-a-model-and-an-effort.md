Written when this phase opens, per the method. This file exists now only so the roadmap entry's
`plan:` path is not a promise with nothing behind it; the phase is `planned`, which needs no plan,
and the five sections below will be written from this prose plus whatever accumulates.

rather than a value a fork left behind.

multi-step work, and the phase ends having made the kit slower and no cheaper.
